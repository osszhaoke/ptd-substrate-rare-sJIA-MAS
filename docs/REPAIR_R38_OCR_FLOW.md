# R38：OCR 录入流程修复

## 变更

本片修复了用户反馈的录入流程歧义：选图后点击“下一步：核信息”只打开本机核对页，不上传；只有“上传并识别”才调用在线 OCR。动态流程控制器此前会在选图或识别等待时把按钮改回旧文案，已统一为“下一步：核信息（不上传）”。

AST/ALT 仍按中文名称显示，并保留英文缩写作为辅助标签；前白蛋白的报告单位 `g/L` 经过字段映射后保留，不用默认单位或参考区间补写。未来可在指标词典层增加 LOINC 编码，本片不扩大医学映射范围。
