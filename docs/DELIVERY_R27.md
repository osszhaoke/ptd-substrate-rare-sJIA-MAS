## 先安全重开一次本机OCR

此次发现19张合法JPEG带有文件尾附加信息，旧网关会误拒。这个修复属于后端Python，现有密钥进程不会因静态页面更新而加载新代码。我们保留了现有服务和密钥，没有读取或迁移其凭据。新启动入口不会自动上传图片或运行收费测试。

1. 结束您之前保持打开的OCR服务窗口，让旧本机服务退出；不要清理浏览器网站数据。
2. 双击[启动R27本机OCR](../runtime/r27-local-verify01/START_R27_LOCAL.command)。若提示LOCAL_PORT_ALREADY_IN_USE_NO_STOP，说明旧服务未退出，入口不会抢占或自动停止它。
3. 在终端隐藏输入SecretId、SecretKey，均只在进程内存，不要粘贴到聊天。出现“R27同版本机服务已启动”后保持窗口打开。
4. 关闭旧测试标签，再打开 <http://127.0.0.1:18791/>。识别用的是终端显示的试用码，不是腾讯密钥。
