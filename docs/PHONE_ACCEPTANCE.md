## 构建独立虚构测试包

```sh
python3 -B -m tools.phone_acceptance --output evidence/r11-phone-新编号
python3 -B -m tools.phone_acceptance --verify evidence/r11-phone-新编号/site
```

部署需另行指定独立HTTPS hostname，根目录为site；不放产品origin子目录，以隔离所有浏览器库。当前本轮仅在Mac全新虚构profile测试工具，不宣称iPhone通过。

填写机型、iOS、Safari/PWA方式并确认只用虚构资料。依次运行1千、1万和64MiB图片；每轮下载JSON再开始下一轮。每轮正式stage→confirm→save，实际加密导出、鉴别和原子恢复，逐项核对事件/回执及原件摘要。保持前台、不锁屏，记录卡死、崩溃或系统杀进程。工具只清理自有UUID虚构库，不清产品默认库，不自动上传结果。

点“模拟空间不足回滚”验证首/中/尾写失败后无部分数据、再正常恢复；结果明确actualQuotaExhaustion=NOT_TESTED。这不能证明物理存储耗尽时Safari表现。不要删除个人资料或填满个人手机来制造故障。

本版进度最多每50ms更新且终态强制显示；结果日志空间不足仍显示/可下载内存报告，初次失败在建库前停止，末尾日志失败不判全流程PASS。若浏览器进程已被系统杀掉，内存报告不能保证保留，须如实记录中断。

通过后下载结果，真正退出浏览器进程再打开，点“核对已保存的测试资料”并下载新结果。新文档读回自动核对；进程真正退出由本人确认，不把刷新当进程退出。未完成窗口不拼接，失败先保存现场。

门槛：心跳p95≤250ms、格式3单帧密码缓冲≤262145字节；本版读窗≤1MiB。总内存峰值Safari不可提供时写未测，不拿缓冲上限冒充。iPhone物理峰值和真实低空间未得证据，D05保留P2。规则专家/独立Tester/本人签收另记。

实际产品另验：四页/三卡/日历/字号；选图或手填→核信息→明确确认保存→来源原图→问诊选状态/给话术/可选问AI→备份取消/恢复/不同进程读回；全部用空白虚构实例，不读或清理现用真实资料。
