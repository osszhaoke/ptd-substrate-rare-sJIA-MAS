# 本机验收启用腾讯 OCR

用户已明确授权“启用OCR”。本机专用终端启动入口已打开；**输入密钥并出现“本机在线 OCR 已启用”才代表准备完成**。密钥只在该终端的进程内存中使用，不写文件，不通过聊天发送。

1. 在刚打开的终端依次粘贴腾讯 SecretId、SecretKey，每项按回车。输入不显示字符是正常的。
2. 等终端显示“本机在线 OCR 已启用”。复制其下的**识别试用码**，不要把腾讯密钥填进网页。
3. 刷新 [本地 H5](http://127.0.0.1:18791/)，进入“录入”，选图片，把终端试用码粘贴到“识别试用码”，勾选同意上传，再点“上传并识别”。识别后逐项核对，由你决定是否保存。
4. 保持终端窗口打开。Ctrl+C 或关闭窗口会停止本机服务。

终端未打开或意外退出，可重新运行 [本机 OCR 启动器](../runtime/local-ocr-r23-01/START_LOCAL_OCR.command)。配置/账本检查失败只回报错误码，勿发密钥或试用码。当前入口不会自动识别、重传、勾选确认或保存。

仅监听 `127.0.0.1:18791`，保持原浏览器数据 origin；不恢复公网，不开放局域网。显式本机传输适配只允许这一固定回环地址；公开产品的 HTTPS 配置要求不改，实际发到腾讯的请求仍用 HTTPS。原精确 Origin、Bearer token、request ID、图片大小、限流、并发和费用保护保持。

用户终端进程沿用原 `~/.ptds/runtime/h5-r02/ocr-budget-v2.json` 及独占锁；缺失/损坏/并行占用即停止，不另建真实预算或重置额度。Agent未读取账本内容或凭据。先通过密钥配置和原账本检查，才替换刚才由本会话启动的无 OCR 本机服务；按实际 PID、完整命令和工程 cwd 核对，只停那个进程。没有自动收费测试。

此入口位于 runtime，是当前已验证核心产品之外的本机操作适配。[准备证据与工具快照](../evidence/local-ocr-r23-01/preparation.json) 包含三项虚构配置/临时账本/假供应商测试，均通过：固定回环限制、公开 HTTPS 及缺密钥拒绝、来源/令牌/去重/预算重开。它们不是核心60项或独立审计新增通过，更不等于腾讯实时识别已成功。

实时状态以 `runtime/local-ocr-r23-01/session.json` 及本机 `/health` 为准，准备回执只是当时快照。没有输入或保存腾讯凭据时，Agent无法替你完成这一步。
